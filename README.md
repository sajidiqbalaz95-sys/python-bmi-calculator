
# 🧮 Python BMI Calculator

A simple, beginner-friendly **Body Mass Index (BMI) Calculator** built with Python. This project calculates BMI based on a user's weight and height and classifies the result into a standard BMI category.

## 📌 Project Overview

The BMI Calculator takes weight in kilograms and height in centimeters, converts the height into meters, and calculates BMI using the formula:

\[
BMI = \frac{Weight\ (kg)}{Height\ (m)^2}
\]

The program then determines the corresponding BMI category.

## ✨ Features

- Calculate BMI using weight and height.
- Accept weight in kilograms and height in centimeters.
- Validate positive weight and height values.
- Classify BMI into four categories:
  - **Underweight:** BMI below 18.5
  - **Normal weight:** BMI from 18.5 to below 25
  - **Overweight:** BMI from 25 to below 30
  - **Obese:** BMI of 30 or above
- Handle invalid input using exception handling.
- Display BMI results rounded to two decimal places.
- Use functions and type hints for readable, organized code.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concepts:** Functions, conditional statements, type hints, exception handling, user input, and formatted strings.
